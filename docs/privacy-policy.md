# Privacy Policy

**App:** FocusKiosk  
**Last updated:** August 18, 2026

## Overview

FocusKiosk is a managed kiosk browser application deployed by organizations to restrict a device to displaying a single website. It is distributed exclusively to organizational devices via Mobile Device Management (MDM) and is not available to the general public.

## Data Collection

FocusKiosk does not collect, store, transmit, or share any personal data. The app does not:

- Create user accounts
- Track usage or analytics
- Send data to any external servers operated by this app
- Use advertising identifiers
- Access contacts, photos, or location

## Camera

FocusKiosk requests camera access solely to allow administrators to scan QR codes when configuring the kiosk URL. No images or video are stored or transmitted by the app. Camera access is optional and only used during the configuration process.

## Web Content

FocusKiosk displays web content from a URL configured by the deploying organization. The privacy practices of that website are governed by the website operator's own privacy policy, not this one.

## Managed Configuration

When deployed via MDM, the deploying organization may push configuration values (such as the homepage URL) to the app. This data is provided by the organization's IT administrator and is not collected by this app.

## Contact

For privacy-related questions, contact the organization that deployed this app to your device.
